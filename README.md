# 🌱 Agrinho 2026

## Agro forte, futuro sustentável

### 📖 Sobre
Projeto desenvolvido para o Agrinho 2026 com o objetivo de conscientizar sobre a importância da sustentabilidade no campo, mostrando como a produção agrícola pode crescer em equilíbrio com o meio ambiente.

### 🎯 Objetivos
- Promover a educação ambiental.
- Incentivar práticas sustentáveis.
- Valorizar o agronegócio responsável.
- Preservar os recursos naturais.

### 🌎 Conclusão
A união entre tecnologia, produção e preservação ambiental é fundamental para garantir um futuro sustentável para as próximas gerações.
